# sheafs

Архив отсканированных рукописных лекций по теории пучков (на русском).

## Состав

- `lecture-01/` — первая лекция: упорядоченные сканы тетради в клетку (`01.jpg` …) + `manifest.md` (соответствие scan-ID → страница).
- `lecture-02/` — сканы второй лекции, её исходник `lecture-2.tex` и PDF.
- `lecture-03/` — сканы третьей лекции. Порядок страниц следует проверять по рукописной фолиации; часть кадров может перекрываться.
- `konspekt-teoriya-puchkov.tex` / `.pdf` — сводный конспект лекций 1–3, разбитый **по темам**, а не по лекциям: локальное и глобальное, предпучки, ростки, пространство ростков и ассоциированный пучок, прокачивание и его универсальность, ядро/образ/точность, глобальные сечения, фласковые пучки и когомологии. На полях — пояснения (`marginnote`).
- `parts/` — куски исходника `lecture-02/lecture-2.tex`, нарезанные по разделам. Сводный конспект подключает их через `\input` в тематическом порядке, поэтому рисунки и разборы лекции 2 сохраняются дословно. Правки содержательных ошибок нужно вносить и в `lecture-02/lecture-2.tex`, и в соответствующем куске в `parts/`.
- Сборка сводного конспекта: `xelatex konspekt-teoriya-puchkov.tex` (два прохода; XeLaTeX). Формат страницы нестандартный (21×28 см) — так помещается полоса с пояснениями.
- `AGENTS.md` — правила работы со сканами (исходник — `*.jpg`, не удалять/не пережимать без спроса).
- Книги:
  - Годеман Р. — Алгебраическая топология и теория пучков (1961, Издательство иностранной литературы) — `.djvu`.
  - Манин Ю. И. (под ред. Лейтеса Д. А. и Львовского С. М.) — Введение в теорию схем и квантовые группы (2012, МЦНМО) — `.pdf`.

Имена вида `5287699…jpg` — это ID сканирования, а не порядок страниц. Истинный порядок устанавливается по рукописной нумерации; для лекции 1 он зафиксирован в `lecture-01/manifest.md`.
