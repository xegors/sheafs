# sheafs

Архив отсканированных рукописных лекций по теории пучков (на русском).

## Состав

- `lecture-01/` — первая лекция: упорядоченные сканы тетради в клетку (`01.jpg` …) + `manifest.md` (соответствие scan-ID → страница).
- `AGENTS.md` — правила работы со сканами (исходник — `*.jpg`, не удалять/не пережимать без спроса).
- Книги:
  - Годеман Р. — Алгебраическая топология и теория пучков (1961, Издательство иностранной литературы) — `.djvu`.
  - Манин Ю. И. (под ред. Лейтеса Д. А. и Львовского С. М.) — Введение в теорию схем и квантовые группы (2012, МЦНМО) — `.pdf`.

Имена вида `5287699…jpg` — это ID сканирования, а не порядок страниц. Истинный порядок устанавливается по рукописной нумерации и фиксируется в `lecture-01/manifest.md`.
